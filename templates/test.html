📤 Step 1 — Deploy Script to Target LPAR

Deploy vios_res_client.sh to a target AIX LPAR via SFTP. After deploying, you'll get the exact command to run yourself.

🖥️ Step 2 — Run the test manually on the LPAR

When the script prints >>> SHUT DOWN/RESTART THE TARGET VIOS NOW <<<, go trigger that VIOS shutdown/restart manually from the HMC. Wait for the script to finish and package the results (tar.gz) before clicking "Fetch Results" below.
