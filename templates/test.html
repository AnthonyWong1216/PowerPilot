🔄 VIOS Network Resilience — Configuration

Deploy vios_res_client.sh to a target client LPAR. Monitors network interfaces (ping, entstat) before/during/after a VIOS shutdown or restart. You must trigger the VIOS action on the HMC manually when prompted.

🎯 Ping Target IPs

Optional: add IP addresses to ping during the test (e.g. gateways, remote hosts). Each IP is mapped to a network interface (en0, en1, …) on the target LPAR.

🗄️ VIOS Fibre Channel Resilience — Configuration

Deploy vios_res_client.sh to a target client LPAR. Monitors FC adapters (fcs*), disk paths (lspath/hdisk*), and I/O continuity before/during/after a VIOS shutdown or restart. You must trigger the VIOS action on the HMC manually when prompted.

Note: If you also selected “VIOS Network Resilience” on the same LPAR, both network and FC monitoring run together in one execution — the script captures everything.

⚙️ CPU & Memory Benchmark — Configuration

Deploy test_cpu_memory.sh, mt_cpu_benchmark.pl, and mt_mem_benchmark.pl to the target LPAR and run CPU + memory benchmarks.

📀 I/O Performance — Configuration

Deploy test_io_performance.sh (and optionally fio) to the target LPAR and run disk I/O benchmarks (sequential read/write, random read).
